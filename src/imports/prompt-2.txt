Prompt

Design a high-quality, professional desktop web application UI for:

CRYPTAVISTA
Enterprise Cryptographic Discovery & Analysis Tool

The application analyses multiple enterprise applications to discover cryptographic assets, assess post-quantum risk, prioritize migration, and recommend suitable PQC or hybrid alternatives.

DESIGN GOAL

The user experience must be extremely clear and intuitive. A first-time user should immediately understand:

What is being analysed
How many applications are being monitored
Which applications require attention
Where to click next
How to move from high-level portfolio analysis into detailed application analysis

Do not make the interface look like a generic AI dashboard, a cybersecurity hacker interface, or a student project.

The design should feel like a polished enterprise security and analytics product used by security architects and cryptography teams.

Use a clean, flat, elegant interface with excellent information hierarchy.

Avoid:

Dark hacker-style UI
Neon colours
Excessive gradients
3D cards
Heavy shadows
Glassmorphism
Excessive rounded elements
Too many charts on one screen
Dense technical text
Decorative AI elements
Confusing dashboards

Use:

Light background
White or very subtle tinted surfaces
Thin borders
Clear spacing
Professional typography
Muted enterprise colour palette
Strong visual hierarchy
Minimal icons
Flat design

The application should feel similar to a real enterprise security platform.

UX REQUIREMENTS

The interface must follow this hierarchy:

Portfolio Overview
        ↓
Select Application
        ↓
Application Overview
        ↓
Discover → Verify → Assess → Prioritize → Recommend
        ↓
Report

Do not force users to understand technical architecture before using the application.

Show high-level information first.

Reveal technical details only after the user clicks into an application or analysis stage.

Every page should have one obvious primary action.

The interface must feel calm, organised, trustworthy, and easy to navigate.

TECH STACK VISUALIZATION SUPPORT

The UI should support:

React.js frontend
Tailwind CSS
FastAPI backend
MongoDB
NetworkX and Pandas analytics
D3.js for timelines
Cytoscape.js for dependency graphs
Recharts for risk and portfolio charts
CBOMkit and CycloneDX for cryptographic inventory and CBOM generation

Do not display the entire technical stack prominently to end users.

Keep technical implementation details inside architecture documentation, not cluttering the product interface.

FINAL VISUAL REQUIREMENT

Create a clean enterprise application with:

Excellent spacing
Clear navigation
Simple user journey
Strong information hierarchy
Minimal cognitive load
No unnecessary empty areas
No clutter
No confusing technical overload

The first screen should immediately communicate:

“These are the enterprise applications being analysed. These are the systems that need attention. Click an application to understand its cryptographic and quantum migration risk.”

The overall experience should feel polished enough for a Smart India Hackathon prototype and an enterprise cybersecurity analytics tool, with a clear journey from portfolio → application → analysis → recommendation → report.
